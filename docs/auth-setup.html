Activar el registro público de PULSE

El error observado es «email rate limit exceeded». El correo integrado de Supabase es para pruebas, tiene una cuota reducida y limita los destinatarios. Para admitir usuarios externos hay que configurar un servicio de correo de producción. Cambiar el formulario no elimina este límite del servidor.

  1. Elige un dominio que controles y un proveedor de correo transaccional compatible con SMTP (por ejemplo, Resend, Postmark o Amazon SES). El registro del dominio y cualquier coste del proveedor corresponden al propietario; no se ha contratado ninguno desde esta sesión.
  2. Verifica el dominio con los registros DNS que indique el proveedor. Configura SPF y DKIM y sigue sus indicaciones para DMARC. Crea una dirección remitente del dominio verificado.
  3. Abre Authentication → Email → SMTP y activa Custom SMTP. Introduce el host, puerto, usuario, contraseña y remitente que proporcione tu servicio. Guarda los secretos en el panel, nunca en GitHub ni en el chat.
  4. En URL Configuration, configura Site URL como https://jo3lnta.github.io/pulse-app/ y permite esa misma URL como redirect. El registro nativo usa la web para confirmar el correo y restablecer contraseñas, y luego el usuario vuelve a la app para entrar.
  5. Mantén activada la confirmación del correo. Ajusta las cuotas en Authentication → Rate Limits según lo que admita el proveedor. No basta con subir un límite si sigue activo el proveedor integrado.
  6. Prueba con una dirección externa real: crear cuenta, recibir confirmación, confirmar, iniciar sesión, cerrar sesión y recuperar contraseña. Comprueba el spam, los registros de Supabase y el panel del proveedor si no llega el correo.
